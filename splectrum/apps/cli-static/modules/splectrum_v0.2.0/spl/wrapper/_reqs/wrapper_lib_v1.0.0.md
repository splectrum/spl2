# wrapper_lib

## Purpose

Wrapper business logic for tool integration. Provides helpers for executing external tools with passthrough or method modes.

## Exports

| Function | Purpose |
|----------|---------|
| executePassthrough | Run tool in passthrough mode |
| executeMethod | Run tool with method handling |
| Various | Tool execution helpers |

## Self-eval

- [ ] Uses factory pattern with create(module)
- [ ] Supports passthrough mode
- [ ] Supports method mode with argument parsing
