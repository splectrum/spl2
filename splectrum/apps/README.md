Root node of the apps structure. Activity center - all activities organized here.

| Type | Purpose |
|------|---------|
| System app | Node management, design and implementation experience |

## Structure

Currently flat. Each subfolder is an app with its own README and entrypoint.

## Relationship

- App (apps/) handles client interaction
- Session (runtime/) handles internal processing
- Same name links them
