# spl/dev API

**Type:** API (api_node)
**Specification:** `_reqs/spl_dev_api_overview_v1.0.0.md`

## Overview

Dev Environment API for autonomous development with test-driven implementation.

**Purpose:** Enable AI to implement well-specified work packages with self-evaluation quality control.

## Methods

- `create/` - Create dev environment shell
- `install/` - Install base packages (planned)
- `submit/` - Submit work package (planned)
- `cycle/` - Run test cycle (planned)
- `status/` - Report current state (planned)
- `extract/` - Extract completed module (planned)
- `destroy/` - Clean up environment (planned)

See `_reqs/` for detailed requirements and self-evaluations.
