# friction

## Spec

Resistance that impedes flow or progress. Force that makes things harder than they could be.

Can be felt as:
- **Internal:** anxiety, confusion, cognitive load, uncertainty
- **External:** unclear requirements, tool limitations, blockers, communication issues

Sources: technical complexity, emotional discomfort, misunderstanding, tool limitations.

Not inherently bad - some friction is protective (requirements create friction against premature action). But unintended friction is a signal.

Primary partnership health metric.

Scope: Global.

Purpose: Continuous assessment signal. When friction increases, investigate source and address.

## Self-eval

- [ ] Both internal and external considered
- [ ] Technical and emotional components assessed
- [ ] Friction increase triggers investigation
- [ ] Distinguishes protective vs unintended friction
