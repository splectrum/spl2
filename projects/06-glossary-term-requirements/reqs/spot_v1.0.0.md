# spot

## Spec

Activity-based location in repository structure. Not just a folder, but a place where specific work happens.

Like rooms in a house - defined by what you do there, not just what they contain.

Scope: Global.

Purpose: Stable landmark for navigation. Return to different spots for different activities.

## Self-eval

- [ ] Activity is defined
- [ ] Purpose is clear
- [ ] Contents support the activity
- [ ] Navigation role understood
