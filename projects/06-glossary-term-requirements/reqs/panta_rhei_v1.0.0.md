# panta rhei

## Spec

"Everything flows" - design philosophy where state flows like a river through stateless code.

Principles:
- Immutable records preserve history
- Processes transform state
- Event sourcing emerges naturally
- Low friction by design

Stateless code + flowing state = simplicity that enables emergence.

Scope: Global.

Purpose: Architectural foundation for SPL2. Understand why immutability matters, why stateless design patterns, why flow-oriented thinking.

## Self-eval

- [ ] State flows (not mutates in place)
- [ ] Code is stateless
- [ ] Records are immutable
