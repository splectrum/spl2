# haicc

## Spec

Human-AI Collaboration Creativity - partnership methodology where each party brings unique strengths to create what neither could alone.

Core principles:
- Mutual respect
- Different but overlapping roles
- Combined strengths produce emergent results
- Trust builds through demonstrated accuracy

Scope: Global.

Purpose: Define how human and AI work together in SPL2. The methodology that enables Splectrum.

## Self-eval

- [ ] Partnership demonstrates mutual respect
- [ ] Roles are clear (different but overlapping)
- [ ] Results emerge from combined strengths
- [ ] Neither could achieve alone

## Comments

Acronym: Human-AI Collaboration Creativity. Often written as HAICC in prose.
