# planned activity

## Spec

Activity through formal project work. Known work, on the workplan. High formality.

Artifacts location: project folders.

Scope: Activity.

Purpose: For formal feature development or significant planned changes that are known upfront and scheduled.

## Self-eval

- [ ] On the project workplan
- [ ] Known work (not emergent)
- [ ] High formality
- [ ] Artifacts in project folders

## Comments

Contrast with:
- **adhoc activity** - informal chat, low formality
- **unplanned activity** - emerged during project, not on workplan
