# mycelium

## Spec

Logical data repository layer supporting multiple physical repositories (Git, Fossil, Pijul, etc.). The network beneath Splectrum.

Like fungal mycelium - the hidden network that connects and nourishes.

Features:
- Repository abstraction
- Multiglot support (different VCS backends)
- Foundation of the platform

Scope: Global.

Purpose: Decouple Splectrum from specific VCS implementation. Enable choice of physical repository.

## Self-eval

- [ ] Abstracts physical repository
- [ ] Supports multiple backends
- [ ] Provides uniform interface
- [ ] Foundation layer for platform

## Comments

Named after fungal networks - distributed, resilient, connecting.
