# autonomy

## Spec

Freedom to act within defined boundaries. Constraints create freedom: requirements + self-evaluation tools define the fencing, autonomy operates within.

Prerequisites for granting autonomy:
1. State requirements (what needs to be achieved)
2. Define self-evaluation tools (how to verify)

Without boundaries, no autonomy can be granted (no way to verify success).

Trust builds through accurate self-evaluation. Boundary expands with evidence.

Context-bound always - never absolute.

Scope: Global.

Purpose: Enable self-directed execution through clarity rather than vagueness.

## Self-eval

- [ ] Requirements clearly stated before autonomous work
- [ ] Self-evaluation tools defined
- [ ] Boundaries enable rather than restrict
- [ ] Trust builds through accurate self-eval

## Comments

The paradox: fencing enables autonomy. Without the fence, there can be no freedom within it.
