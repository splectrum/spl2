# register

## Spec

Log of what exists for a specific item type. Inventory or catalog of items, conditioned or not.

Examples: user register, project register, CIP register.

Mutable - updated as items are added, removed, or change status.

Scope: Global.

Purpose: Track all instances of a specific item type in one place.

## Self-eval

- [ ] Tracks specific item type
- [ ] Comprehensive inventory
- [ ] Updated as items change
- [ ] Clear item structure
