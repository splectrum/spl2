# patch

## Spec

Third component of semver (x.y.z). Increment for bug fixes that are backward compatible.

When to increment: Fixes issues without adding features or breaking changes.

Purpose: Signal corrections without changing behavior or capabilities.

## Self-eval

- [ ] Indicates backward-compatible bug fixes
- [ ] Third component of version string
- [ ] Does not add new features

## Comments

Example: 1.0.0 → 1.0.1 (bug fix)
