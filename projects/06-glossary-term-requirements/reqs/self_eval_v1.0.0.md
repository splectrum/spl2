# self-eval

## Spec

Self-evaluation - verification against reqs using defined tools/criteria. The TEST component of reqs (spec + self-eval = req).

Enables autonomy through accountability. Must be honest and accurate - trust builds through accurate self-eval, erodes through inaccurate.

Self-eval tools defined before work begins (part of the fence).

Purpose: Enable autonomous verification. If I can check my own work against clear criteria, I don't need external review. Trust expands with demonstrated accuracy.
