# single concern

## Spec

Within a defined context, aim to deal with one thing only.

Criterion for boundaries and granularity.

Scope: Global.

Purpose: Clear separation of concerns. When something addresses multiple concerns, split it.

## Self-eval

- [ ] Context is defined
- [ ] One thing being dealt with
- [ ] Multiple concerns identified and split
- [ ] Boundaries are clear

## Comments

Applies to: modules, files, artifacts, functions, documents. When concern becomes multiple concerns, split.
