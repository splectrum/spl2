# minor

## Spec

Second component of semver (x.y.z). Increment for new features that are backward compatible.

When to increment: New functionality added, existing consumers continue to work.

Purpose: Signal new capabilities without breaking existing usage.

## Self-eval

- [ ] Indicates new backward-compatible features
- [ ] Second component of version string
- [ ] Increment resets patch to 0

## Comments

Example: 1.0.0 → 1.1.0 (new feature)
