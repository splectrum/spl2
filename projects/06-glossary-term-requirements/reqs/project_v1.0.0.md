# project

## Spec

Formal work unit for delivering products. Replaces sprint in traditional agile - we work with backlog and project.

A project is a set of related products (user stories). Since AI executes single-threaded (per repo), project is the means to:
- Deliver products / user stories
- Ensure maintenance activities are done as part of the cycle

Project types (blank project, exploration project, etc.) allow dealing with complex delivery appropriately.

Structure:
- PROJECT_BRIEF.md
- PROJECT_PLAN.md
- DAILY_LOG.md
- RISKS.md
- Closure artifacts

Scope: Global.

Purpose: Structured delivery with quality criteria and closure process.

## Self-eval

- [ ] Has required project artifacts
- [ ] Products are defined
- [ ] Project type is appropriate for work
- [ ] Closure process followed
