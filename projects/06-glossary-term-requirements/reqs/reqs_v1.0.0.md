# reqs

## Spec

Requirements - clear statement of what needs to be achieved. Defines the fence for autonomy. Without reqs, no autonomy can be granted (no way to verify success).

Structure: spec + self-eval
- **Spec** - what needs to be achieved
- **Self-eval** - how to verify

Purpose: Enable autonomy through clarity. Balance request (what's needed) with support (methodology, patterns). Success criteria must be testable/verifiable.

Constraints create freedom: the fence enables the autonomy within.

## Self-eval

- [ ] Has clear spec stating what needs to be achieved
- [ ] Has self-eval with verifiable criteria
- [ ] Success criteria are testable (not vague)
- [ ] References req type (first line)
- [ ] Balances request with support (not just "what" but enabling "how")
