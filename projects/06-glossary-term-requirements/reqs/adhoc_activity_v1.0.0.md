# adhoc activity

## Spec

Change activity through informal "chat while we work". Emergent, low formality.

Artifacts location: chats/ (captures) or chats/immutables/ (requirements, designs).

Scope: Activity.

Distinction from other activity types:
- Adhoc: emerges during informal conversation
- Unplanned: emerges during project work, handled at closure
- Planned: formal backlog item

Purpose: Enable lightweight changes when formal project overhead not needed.

## Self-eval

- [ ] Emerged during informal conversation
- [ ] Artifacts in chats/ or chats/immutables/
- [ ] Low formality appropriate
- [ ] Clear distinction from unplanned/planned activity

## Comments

Example: Discovering a new pattern while discussing something else, capturing it in chat, creating a versioned immutable for the requirement.
