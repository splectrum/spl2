# twin pair methodology

## Spec

Create deliverable and req in tandem. Discover through doing what's actually needed. Skip work when discovery reveals it's unnecessary.

The req and deliverable co-evolve - building one reveals what the other needs.

Scope: Methodology.

Purpose: For exploration where requirements aren't clear upfront. Let the work inform the req.

## Self-eval

- [ ] Deliverable and req created together
- [ ] Discovery through doing
- [ ] Unnecessary work skipped
- [ ] Co-evolution happening

Used in exploration projects. Chicken and egg pattern in action.
