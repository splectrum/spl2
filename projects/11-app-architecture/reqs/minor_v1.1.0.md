## Spec

2nd part of version; for non-disruptive upgrades.

New features or enhancements that don't break existing usage.

### Character

- Second position: x.Y.z
- Non-disruptive: existing usage continues to work
- Additive: new capability

## Self-eval

- [ ] Indicates non-breaking enhancement

## Comments

Part of semver pattern: major.minor.patch
