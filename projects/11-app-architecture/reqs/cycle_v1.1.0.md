## Spec

To do one or more iterations (API method).

Execute a repeating process, return, resume pattern.

### Character

- Iterative: can repeat
- Resumable: picks up where left off
- Incremental: progress per cycle

## Self-eval

- [ ] One iteration completed
- [ ] Can resume for next iteration

## Comments

Common API method for iterative workflows like dev/test cycles.
